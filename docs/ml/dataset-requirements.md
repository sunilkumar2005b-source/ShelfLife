# ShelfLife - Machine Learning Dataset Requirements & Ingestion Guide

## 1. Machine Learning Honesty Rule

In accordance with strict academic guidelines:
- **No Fabricated Data**: We do not invent synthetic CSV rows or pretend that a model was trained on non-existent data.
- **Traceability**: Every metric ($R^2$, RMSE, Accuracy, F1-Score) and prediction presented to faculty must be traceable from:
  $$\text{Raw Dataset} \longrightarrow \text{Validation} \longrightarrow \text{Train/Test Split} \longrightarrow \text{Preprocessing} \longrightarrow \text{Model Training} \longrightarrow \text{Evaluation} \longrightarrow \text{Saved Model Artifact}$$

## 2. Directory Structure

```text
ShelfLife/
└── data/

```

> [!IMPORTANT]
> The original files placed under `data/raw/` must NEVER be modified directly. All transformations, imputation, one-hot encoding, and feature scaling must be applied via Python scripts saving reproducible outputs under `data/processed/`.

## 3. Supported Machine Learning Problem Formulations

### Task A: Retail Demand Forecasting (Regression / Time-Series)
- **Objective:** Predict future sales units of perishable products to prevent stockouts and over-purchasing.
- **Target Variable ($y$):** `quantity_sold`, `units_sold`, or `daily_sales`.
- **Expected Features ($X$):**
  - `date` or `timestamp` (Day of week, Day of month, Month, Year)
  - `product_id` or `product_name`
  - `category` (Dairy, Bakery, Vegetable, Fruit)
  - `selling_price` or `unit_price`
  - `discount_applied` or `promotion_flag`
  - `ambient_temperature` or `rainfall` (optional environmental features)

---

### Task B: Spoilage Risk Prediction (Classification / Probability Estimation)
- **Objective:** Predict probability of batch degradation or classify risk tier (Low, Medium, High).
- **Target Variable ($y$):** `spoilage_risk` ('Low'/'Medium'/'High') or `is_spoiled` (0 / 1).
- **Expected Features ($X$):**
  - `category` or `product_type`
  - `shelf_life_days` (total rated fresh life)
  - `days_in_storage` or `days_remaining`
  - `storage_temperature` (°C)
  - `storage_humidity` (%)
  - `packaging_type` (vacuum, sealed, open crate)
